# Island Editor

SlumberToggle, an [exlaunch](https://github.com/shadowninja108/exlaunch) code mod for **Animal Crossing: New Horizons 3.0.3**
(build id `FF1D1C05670DB602`). It brings Slumber Island features to your main island, adds an island editor
and stacked cliffs, and lets you switch every feature on or off in game. Tested on Switch (Atmosphère), Eden and Ryujinx.

> **Play offline and back up your save first.** This only works on version 3.0.3, with the game language set to English.

## Features

Each feature can be switched on or off from the **Slumber** phone app, the Island Designer app's
"Slumber settings" menu, or `sd:/slumbertoggle/toggles.txt` (re-read every second; log in `log.txt`).

| Switch | What it does |
| --- | --- |
| `slumber_dpad` | Slumber catalog and time/weather screen on the D-pad |
| `instant_bridges` | Bridges and inclines finish instantly |
| `trees_anywhere` | Plant trees anywhere |
| `outdoor_rugs`, `outdoor_partition_walls` | Rugs and partition walls outdoors |
| `level4_access` | Reach level-4 cliffs |
| `slumber_weather` | Pick sunny or rain/snow on your island from the Slumber time screen |
| `slumber_phone_app` | A "Slumber" NookPhone app that opens the settings (needs Nook Miles+) |
| `fast_terraform` | Cliff and water building plays fast (`terraform_speed=1..60`) |
| `slumber_hud` | Slumber's fence / helper / bag HUD and build modes (+) on your island |
| `island_editor` | Happy Home Paradise's outdoor editor on your island: place items anywhere, move houses and buildings, edit house exteriors (needs HHP) |
| `unlock_all` | All phone apps, construction permits and HHP unlocks |
| `cliff_stack` | The cliff tool stacks a cliff on a flush edge, instantly, with solid walls |
| `slumber_terraform`, `terraform_near_trees` | Experimental, off by default |

## Install (players)

Download the zip from **[Releases](../../releases)** and follow its README:

- **Switch (Atmosphère):** copy `atmosphere/` to the root of the SD card.
- **Eden / yuzu-based:** right-click the game > *Open Mod Data Location*, and copy the mod folder in (it holds `exefs/` and `romfs/`).
- **Ryujinx:** right-click the game > *Open Mods Directory*, and copy the mod folder in.

If the game hangs on the loading screen in an emulator, check that the emulator's GDB stub / debugger is off.

## Build (developers)

Needs [devkitPro](https://devkitpro.org/) with devkitA64 and Python 3.

```bash
./exlaunch.sh build        # -> deploy/subsdk8 + main.npdm
```

`source/program/main.cpp` holds the mod; `source/program/patches.inc` holds the instruction-word switches
(generated by `tools/gen_patches.py`); `offsets.hpp` lists the 3.0.3 addresses.

The RomFS part (menu texts, event flow, phone icon, the HUD stage entry) is **not in this repository**, since
it is modified Nintendo game data. Build it from your own dump of the game:

```bash
pip install zstandard evfl
python tools/build_romfs.py <your RomFS dir> <your Player_ConstructionLicenseApp.bfevfl> <out romfs dir>
```
