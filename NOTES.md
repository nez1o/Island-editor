# Developer notes

Working notes for continuing this mod on any machine (or with an AI assistant). Everything is for
**ACNH 3.0.3, main build id `FF1D1C05670DB602...`**; offsets are relative to the start of `main`
(`exl::util::GetMainModuleInfo` / `GetTargetOffset`). Status as of v0.61 (2026-11).

## Layout

| Path | What |
| --- | --- |
| `source/program/main.cpp` | The whole mod: feature table, toggles.txt watch thread, all hooks |
| `source/program/patches.inc` | Instruction-word switches `{offset, original, patched}` per feature (generated by `tools/gen_patches.py`) |
| `source/program/edge_table.inc` | Cliff edge-piece table (neighbour mask -> model, angle) used by `cliff_stack` |
| `source/program/offsets.hpp` | Shared 3.0.3 offsets |
| `source/program/slumber_app.cpp`, `.hpp` | The Slumber app's own screen (drawn by the module, see below) |
| `source/program/app_font.inc` | Its font bitmaps, generated by `tools/gen_font.py` from Inter |
| `source/program/gyroid_sprite.inc` | Gyroid pixel art (menu watermark + phone icon), from `tools/gyroid_art.py` |
| `tools/build_romfs.py` | Builds the RomFS part from a dump (menu texts, event flow, phone icon, HUD stage entry) |
| `tools/stage_hud.py`, `phone_icon.py`, `bntx.py`, `swz.py`, `yaz0.py` | Helpers used by `build_romfs.py` |

The module loads as **subsdk8** (so it can sit next to Aden Modmenu at subsdk9) and ships the same `main.npdm`.

## Build and test

```bash
./exlaunch.sh build      # -> deploy/subsdk8, deploy/main.npdm
```

Copy `deploy/subsdk8` (+ `main.npdm`) into the mod's `exefs/` folder:

- Switch: `atmosphere/contents/01006F8002326000/exefs/`
- Eden: Windows `%APPDATA%\eden\load\01006F8002326000\SlumberToggle\exefs\`, Linux `~/.local/share/eden/load/01006F8002326000/SlumberToggle/exefs/`
- Ryujinx: Windows `%APPDATA%\Ryujinx\mods\contents\01006f8002326000\SlumberToggle\exefs\`, Linux `~/.config/Ryujinx/mods/contents/01006f8002326000/SlumberToggle/exefs/`

Settings and log: `sd:/slumbertoggle/toggles.txt` and `log.txt` (Eden: `<eden data>/sdmc/slumbertoggle/`).
The log's first line shows the version and main base, so it is the quickest way to see that the right build loaded.

Gotchas:
- **Eden/yuzu infinite loading = GDB stub enabled** (Configure > Debug). It suspends the game until a debugger
  attaches; the mods are not the cause. (If the stub is off and `log.txt` stays empty, check Eden's log for a
  `BindJumpSlotRel` panic: see the next point.)
- **exlaunch's module scan and the SDK.** On Eden the SDK's data segment starts with a read-only RELRO part;
  the stock scan expected RW right after rodata, skipped the SDK and took this module as `ModuleIndex::Sdk`.
  `mem_layout.cpp` now accepts the RELRO pages. Don't use `exl::reloc::GetSymbol` on game modules: it can
  (re)initialise the rtld module object it is handed (a wrong one broke lazy binding -> `BindJumpSlotRel`
  panic, infinite loading), and it only reads DT_HASH, while ACNH's sdk and subsdk0 only have DT_GNU_HASH.
  `SdkSymbol` in `main.cpp` does a read-only GNU/SysV hash lookup instead.
- **Phone icon texture match.** Critterpedia's `DeviceIconBook2^x` (180x180) can also start within 64 KB before
  the icon signature; `TexInit` keeps the texture that starts closest before it (one "animating it" log line).
- Other installed mods on the same setup: ACNH_PlaceAnywhere and ACNH_MultiplayerDecorationUnlock (exefs IPS)
  and tmouh's 60 FPS + SpeedFix. Their patched words were checked: none overlap this mod's hooks or patches.
- Before hooking an address, check the instruction before it is `ret`/`b`/`udf` (a real function start).
  v0.27 hooked a mid-function address and crashed after loading.
- Never put GDB breakpoints on hot render functions (e.g. `0x146ab80`): a render thread hit one and crashed the
  game. Use read-only memory dumps for those.
- **Hook pool**: every trampoline hook takes 200 bytes of the JIT area (`setting.hpp` `JitSize`). When it runs
  out, exlaunch aborts in `AllocForTrampoline` at boot and the game sits on the loading screen (Eden log:
  "Failed: AllocForTrampoline"). Raised to 0x8000 in v0.63 (~160 hooks).
- Don't write the SD card from game threads (caused ~1 s hitches): `Log()` queues lines for the watch thread.

## Features: how they work

### Instruction-word switches (`patches.inc`)
`slumber_dpad`, `instant_bridges`, `trees_anywhere`, `outdoor_rugs`, `outdoor_partition_walls`, `level4_access`
(on by default), `slumber_terraform`, `terraform_near_trees` (experimental, off). Turning one on writes the
patched words, off restores the originals. `slumber_terraform` is special: its words depend on where the module
loads, so they are filled in at run time (copy of the map-attribute table with the Slumber bit 32 set).

### In-game menu
The menu (Slumber phone app) toggles island flags named `cLand:SLT_<key>`; hooks on the land flag get
`0x263ea30`, get-bool `0x263f0a0` and set `0x263f3c4` turn those into feature switches. Changes are saved to
toggles.txt.

### Slumber phone app
Uses the Nook Miles app slot (app 6), which the phone hides once Nook Miles+ (7) is unlocked. Hooks: unlocked
`0x2e5a0e0`, badge `0x2e5fff8`, launch (inline at `0x2dffb64`, x8 = handler) and flow name `0x2e01c98`. It runs
Island Designer's handler with the entry point of the Slumber menu.

### Slumber app screen (v0.61, not yet tested in game)
Tapping the app closes the phone (handler result +8 = 1, like the editor app) and opens a panel the module
draws itself: no game UI scene and no offsets in main, only SDK exports.
- **Drawing**: `nvnBootstrapLoader` (sdk export, hooked by symbol) is wrapped, so every NVN function the game
  looks up passes `app::WrapProc`. Wrapped: `nvnDeviceGetProcAddress`, `nvnDeviceInitialize` (device),
  `nvnWindowBuilderSetTextures` (window textures), `nvnWindowSetCrop`, `nvnDeviceSetWindowOriginMode`,
  `nvnCommandBufferInitialize` (device fallback), `nvnQueuePresentTexture`. The panel is drawn on the CPU
  into a memory pool (CPU cached, GPU uncached, memory from the sdk's `aligned_alloc`), and before each
  present a command buffer copies it into the presented texture (`nvnCommandBufferCopyBufferToTexture`, one
  copy per row near the rounded corners). No shaders. Command memory is a ring of 4 slots, re-recorded
  every frame. Only RGBA8 / BGRA8 window formats (sRGB or not) are drawn.
- **Input**: `nn::hid::detail::GetNpadStates(int*, State*, int, const NpadIdType&)` and the public
  `GetNpadState(s)` for FullKey / Handheld / JoyDual / JoyLeft / JoyRight are hooked by mangled name. The
  hooks read buttons (NpadBaseState: sampling i64, buttons u64, sticks 4 x s32, attributes) and clear buttons
  and sticks while the panel is open, and until everything is released after B. If the game stops reading
  the controller for 2 s the panel closes by itself.
- **Fallback**: `app::Ready()` (checked when the app is tapped) falls back to the old talk menu (Island
  Designer flow, entry `SlumberApp`) when NVN wasn't seen, the format is unknown, no controller hook ran,
  or memory can't be allocated; the reason is logged. The romfs talk menu is still needed for that.
- Gyroid sprite: hand-placed after a City Folk gyroid picture in `tools/gyroid_design.py` (24x25, eye
  sparkles + blush), which writes `gyroid_sprite.inc`.
- The header gyroid hops and flaps its arms: 1.6 s loop of 8 steps, each half a hop (rest, up 1, up 2,
  up 1 sprite pixels), and the arm pose (frames 0 / 1 of `gyroid_sprite.inc`, left arm down + right up
  or the other way round) swaps every hop. When only the animation changes, just its patch of the header
  is redrawn and flushed (`RedrawGyroid`); a PC check showed it matches a full redraw for every step.
- Sway: while hopping the gyroid also wobbles one sprite pixel sideways (`SwayOf`: up 1 = left, up 1 on
  the way down = right; mirrored on the second hop). The redraw patch is one pixel wider on each side.
- Header notes: two pixel music notes left of the gyroid (`DrawNotes`, drawn at the gyroid's pixel size,
  1-px brown outline) bounce in counter-time like the icon's and wiggle during a blink. `BobNow()` carries
  the wiggle (flag 16, swaps every 50 ms) so the menu and the icon use the same clock. The redraw patch
  covers notes + gyroid, the full header height.
- Sparkle: when a row's value actually changes (A / left / right), four pixel twinkles pop up around the
  gyroid one after another ("+", star, "+"; 6 phases of 0.1 s, `DrawSparkles`). The phase rides in the
  animation state (bits 5+). The redraw patch reaches 5 sprite pixels right of the gyroid and repaints
  frame + paper first, so the header's rounded corner blends exactly like a full redraw (checked on a PC
  for all 168 states).
- Blink: sprite frame 2 (pose 0, eyes shut) replaces the first rest step of loops 0 and 2 of every 5
  (every 3.2 / 4.8 s); the icon has a matching 7th frame. `BobNow()` returns step + 8 while blinking.
- Phone icon animation: the module also wraps `nvnMemoryPoolBuilderSetStorage` / `nvnMemoryPoolInitialize`
  / `Finalize` and `nvnTextureBuilderSetStorage` / `nvnTextureInitialize` / `Finalize`. Pools up to 16 MB are
  scanned (before init) for two ASTC blocks of the romfs icon (`k_IconSig`; block-linear tiling keeps
  16-byte blocks whole); a 180x180 texture created within 64 KB before them is the icon. While it exists,
  each animation step change copies the matching frame (`icon_frames.inc`, 10 frames = 4 steps (hop + sway) x 2 arm
  poses + 2 blink frames (notes wiggled either way, swapped every 50 ms during a blink), the music notes bouncing in counter-time; from `phone_icon.py --frames`; frame 0 = the romfs icon) into it with
  `nvnCommandBufferCopyBufferToTexture` (row stride 36 x 16 bytes). Base mip level only. The copies share
  one recording per frame with the panel. A PC test tiled the icon at block heights 1-16 into random
  data: found every time, no false match. Needs the rebuilt romfs (old icons have no signature).
- Header: "Gyroid's menu", watermark "made by saiplatano" with the gyroid from `gyroid_sprite.inc`
  (any size; drawn about 48 units tall in whole pixels). `tools/gyroid_art.py <picture> <inc> [height]`
  turns a picture into it; the phone icon (`phone_icon.py`) draws the same sprite on a clay tile. The
  phone app's name is MenuDevice label 0090 = "Gyroid's menu" (romfs).
- Look: Animal Crossing palette (cream dotted paper, leaf-green header, yellow cursor, teal ON). Input is
  quick: repeat after 0.2 s, every 50 ms, 25 ms after holding 1 s (several steps per 30 fps frame); the list
  glides to the cursor in about 3 frames.
- Switches changed in the panel set `wanted`; `AppTick` (game thread, frame tick) applies them and the watch
  thread writes toggles.txt (no SD writes from the render thread).
- **Open question - vertical orientation**: with NVN's default lower-left window origin the panel is drawn
  flipped (assuming the presented image is shown flipped); with upper-left it isn't. If it shows upside
  down, set `app_flip_y=1` or `0` in toggles.txt (-1 = auto). The log's "first frame" line shows the window
  size, format, crop and origin mode.
- Preview: the drawing code builds on a PC too (it has a host fallback for the tick counter), which is how
  the layout was checked.

### Slumber weather (`slumber_weather`)
Weather pick hook `0x2cacf14`: builds the sunny/rain records (`0x27e2220` / `0x27e24f0`) in the environment
manager (`*(main+0x4ca7238)+0x65838`, 2 x 0x14c) and NOPs `0x987e14` (`tbz w8,#0`) so map loads keep the pick.

### Slumber HUD + build modes (`slumber_hud`)
- The HUD is the resident UI scene `CloudIslandModeChange`, added to `Stage/Game/MainField.byml`
  (key `2ccc87db`, entries `{691a4d18: mmh3(name)}`, MurmurHash3 seed 0) by `tools/stage_hud.py`.
  Hook `0x32d8b70` (resident creator) returns null when the switch is off.
- `+` (player input bit 0x12, player+0xed0) cycles the mode via `0x24394e8` in the button-handler hook `0x2268cd4`.
  Mode = players[i]+0x13b8 (players array = GOT `0x4ab4fb8`, 0x13f0 each).
- Pocket -> fence/path picker: NOP `0x2df7ea8` (`tbz w9`). Fence picker: NOP `0x24368c8`.
- Unlimited fences: placing = player state 0xa6, enter `0x238c3b0`; `0x238c430` opened during that call in fence mode.
  Pick-up: `0x238d900` with request byte +0x37 bit 0 set (no item given back).
- Path mode keeps path mode: picker `0x2436850`; skip `str wzr,[x27]` at `0x2436d78`, `mov w2,#1` at `0x243733c`.
- Island Designer helmet (`EquipLicenseHelmet`, read via `0x264bce0`) on => designer owns the top-right and `+`;
  HUD page update `0x2c52ce0` / idle `0x2c51f14`. Path mode also sets the helmet (so "designer" = helmet && mode != 2).
  Designer `+` box hidden in path mode by making `0x2dfb378` (`cbz w0`) unconditional before MainScreen updates
  (page-update hook `0x2b0c720`).

### Island editor (`island_editor`)
HHP's outdoor editor on the main island, from a phone app in the hidden DIY Recipes slot (3 or 4).
- Make it run outside HHP: area check `0x13e44ac` -> true, request gate `0x32fa3b0` -> true, warp check `0x15dc334`,
  edit area `0x13b8fc4` = the whole map incl. the 1-acre sea ring (x10..1430, z10..1270; 1 tile = 10 units; the
  island grid is x160..1280, z160..1120). The middle must stay (720, 640): closing is recognised by it.
- Camera/cursor: look-at `0x7f9070` (Vec3 in s0-s2), centring `0x13d5d30`, start `0x13c97d0`, cursor 1.25x via misc
  params `0x13c9440`. Place anywhere: can-place `0x13ea4c0` -> yes.
- Close: teleport to the cursor (warp check + target `0x2309d50`; also write saved pos player+0xba4), clamped to the
  island grid so a cursor out at sea doesn't drop the player in the water. Pressing B first snaps the cursor to the
  area middle (not through `0x13d5d30`) while the edit camera still runs; the camera then keeps the last real spot
  (`s_EditClosing`), otherwise it swung to the map middle for a moment.
- Open request: `UiRequest 0x2df7b98(*(main+0x55b6f18), 0x6f, {player idx}, 0)`.
- **Buildings**: HHP house hover `0x13cef20` -> gate `0x13cfd7c` (inline) -> lookup `0x13d0308` -> `0x13f1bc4` ->
  edit object `0x13ba988`. The mod supplies a fake component (copy of game vtable `0x49a5880`, own slots for pos /
  grab / cancel / drag / valid / drop). Records: `0x1260490(list, i)` (returns via x8). Collision follows via
  `0x2a3cfa0` / `0x2a3a450`. Rebuild at the new spot: spawner `0x2975a38(field+0x1e08, record, idx)`, old actor
  deleted with `0x5fb3d0` once the new body has parts (frame tick on camera apply `0x7a8414`).
- **Exteriors** (X on a house): hooks `0x2a914b0` (get design) / `0x2a91660` (apply), save offsets for villager and
  player houses in `main.cpp`. The menu's theme banner showed "Construction Job Site" on island houses: the
  banner code at `0x345d7bc` reads the vacation home's theme (u16 at +0xd8; 0xffff = none -> theme 0 =
  System `OneRoom_ThemeName` label 0000) and sets it via `0x1aea210` / `0x1aea9c8`. With the editor on, the
  "none" path is skipped (`0x345d7cc` `mov w2, wzr` -> `b 0x345d81c`; `0x345ca38` / `0x345ca6c` also jump
  straight there), so the text stays empty. v0.62 also hides the whole banner on the island: inline hook at
  `0x345d81c` (end of that code, x19 = text object, +0x90 = `T_Text_00` pane) walks the parents
  `N_Center_00` -> `N_Capture_00` -> `N_InOut_00` (zigzag = `P_Line_00`, under `N_Capture_00`) and clears
  `N_InOut_00`'s visible bit. ui2d panes in 3.0.3: +0x18 parent, +0x20 child list root (nodes = child+8),
  +0x50 size, +0x58 flag (bit 0 visible), +0x59 alpha, +0xb0 name. Found with read watchpoints on the
  `OneRoom_ThemeName` string in Eden (`work-tools/eden_gdb.py`; static xrefs missed this site), then a logging
  build that walked the pane tree.
- **Bridges and inclines** (v0.63, tested in game): two extra tabs in HHP's own house exterior menu
  (descriptor `0x4a33ed0` grown to 7 entries, kinds 0x7f / 0x7e, labels from `STR_CategoryName` 1290 / 1291,
  strip panes and `CategoryNum` frames 5/6 added by `tools/bridges_tab.py`). X on a bridge (reach 28) or an
  incline (reach 18) in the editor opens the menu on its tab; the grid shows 8 looks with pictures packed as
  `Layout_HouseShapeIcon_B0..B7` / `S0..S7` (made from 300x300 PNGs given in `BRIDGE_PICTURES`, kept outside
  the repo). Bridges: building records of type 26, record +8 = NHSE `BridgeType` (material x size,
  `k_BridgeIds`); inclines: type 27, +8 = NHSE `SlopeType` (`k_InclineIds`). A pick writes the save record
  and the land list entry, feeds the building spawner, deletes the old actor a few frames later, and
  re-ticks the grid (`0x340de50`). Hovering a cell shows the game's kit name in the cell bubble:
  `0x340b370` (hover -> bubble) runs as the roof tab with made-up ids 60000+ / 60010+, whose
  `STR_HouseRoofName` entries `bridges_tab.py` copies from `Item/STR_ItemName_85_BridgeSlope`.
  - Closing the editor restores its opening snapshot of the island: `KeepOverrides` writes the new id back
    each frame when a record shows up at its old id, so the swap is what gets saved.
  - Walk shape: each building has a slot at FieldMgr+0x26e8 (+0x10 on play modes 1/0x32, else +0x6dc8;
    +8 + index * 0x208). At island load the type switch at `0x2981abc` fills it with a per-type builder:
    `0x2a3a450` houses, `0x2a3aef0` bridges (collision object slot+0xb8, model name slot+0x100), `0x2a3b680`
    inclines (slot+0x160, name +0x1a8). Builders do nothing on a filled slot. `RebuildShapes` runs once the
    editor has closed (the editor's play mode builds nothing): `0x2a3cfa0` (remove: unmark tiles, unregister
    the collision, empty the slot) and then the type's builder. Using the house builder for a bridge gives
    a box you can't walk onto.
  - Hook pool: the extra trampolines needed `JitSize` 0x8000 (`setting.hpp`); running out hangs at boot.
- Not done: Tom Nook-style moves of villager houses (record move alone made the house invisible), camera zoom/tilt
  (rewriting the pose each frame jittered).

### Unlock all (`unlock_all`)
Once per session on the island: player flags via `0x264bfe8(idx*, SafeString*, 1)` for every existing player,
HHP flags via `0x2658bb8(SafeString*, 1)`. Names come from `Bcsv/EventFlagsPlayerParam` and
`EventFlagsWherearenPlayerParam`. HHP story facility flags are deliberately not set.

### Fast terraforming (`fast_terraform`)
Trampolines on the cliff/river tool state exec/exit handlers (`0x229dcd8`, `0x229de80`, `0x229e028`, `0x229e1d0`,
`0x229e388`, river `0x2294f24`..`0x22954c4`, start-acting `0x2290770`) set the player's animation rate
(`terraform_speed`, 1-60).

### Stacked cliffs (`cliff_stack`)
- Decision hook `0x21e37a0` (cliff tool only): if the game refuses (action >= 2), the target tile at
  player+0x764 goes up one level (same level, next to a drop) or down one (one above).
- Applied through the game's own instant terrain update: `0x11ee4e0` (write + mark) -> `0x11ee6e0` (models) ->
  `0x11eeba8` -> `0x11eed50` (collision), with args `{T, T+0x778, *(T+0x58), block*, mode 1, animate, removing}`,
  T = `*(*(*(*(main+0x4ab27a8))+0x1f8)+0xa8)`. Block = 3x3 tiles of 14 bytes (u16 model, u16 var, u8 angle,
  road u16/u16/u8, elevation u8 at +12); grid 112x96, index x*96+z, grid x = world/10 - 16.
- Tall walls: hook `0x146ab80` (per-frame terrain piece instance add; transform 3x4, translation [3],[7],[11],
  pieces at y = elevation*15) draws each lower level again with the right edge piece from `edge_table.inc`.
- `0x11ee4e0` hook also fixes raised tiles the game leaves with model 0 next to a drop (the "hole" after removal).
